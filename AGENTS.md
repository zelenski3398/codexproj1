# Documentation for project updates

Update the root README and the relevant documentation under `docs/` alongside every project update. Record what changed, how it affects players or maintainers, the verification performed, and any known limitations.

Follow the [incremental development journal](docs/development-updates/README.md) and the [update boundary in the README](README.md#development-history-and-update-boundary). Add a dated entry with evidence links, update the journal index, and keep its state file aligned with the README’s source commit marker.

Push completed changes directly to the upstream `main` branch by default. Use another destination only when the user requests one.
