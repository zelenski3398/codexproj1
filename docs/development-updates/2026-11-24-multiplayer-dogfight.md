# 24 November 2026 — First multiplayer 1v1 dogfight

The multiplayer feature branch adds a dedicated Godot authority and browser lobby. Guests retain an authenticated identity and career, can find and challenge another available player, then select opposing sides and aircraft. Both pilots load into a shared Malta duel with a preparation deadline, weapon gating, an authoritative combat boundary, results and rematches. [Source commit](https://github.com/zelenski3398/codexproj1/commit/e1eb1d7b02ed723a385aed938dc7f61538149068) · [Local play and HTTPS hosting guide](../multiplayer-dogfight.md)

The native authority suite passed 21 checks, including runway and airborne starts, weapons gating, waypoint arrivals, crash/reset, actual swept gun hits, mutual-loss results, forfeits, cancellation and duplicate-proof career records. The WebSocket smoke passed guest authentication, discovery, challenge expiry and races, live combat firing, reconnect and two consecutive rematches. Intro, weapons, Malta terrain and Bf 109 regression suites passed. The web release export succeeded. Two isolated Chromium contexts used the exported game through the local same-origin relay, covering guest restore and rename, discovery, a shared accepted match, faction and fighter selection, both starts, gunfire replication, an explicit leave forfeit, and career restore. This run disabled rendering to keep two browser clients responsive on the test machine. A separate rendered Chromium session created a guest through the game UI. Public internet play and deployment remain unverified. GitHub Pages and main were left untouched.
 A native disconnect fixture verified that a player can return to the normal menu if the socket is unavailable.
