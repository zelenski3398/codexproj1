# 24 November 2026 — Loading cinematic soundtrack

The browser cinematic now includes the original stereo soundtrack. Playback starts muted so it can begin automatically while the game loads. Click **Enable intro sound** to hear the soundtrack, or **Mute intro sound** to turn it off. The button and playback disappear when the animated poster opens.
