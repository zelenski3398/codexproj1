# Bundled procedural landscape assets

Generated by `tools/generate_malta_landscape.py` with seed 1942. No runtime
downloads, GIS libraries or generator dependencies are required to play.

| Asset | Size | Channels / use |
| --- | --- | --- |
| `landcover.png` | 2048² | RGBA: dry soil, cultivated land, scrub weights; rubble boundaries |
| `coast_distance.png` | 1024² | R: land coverage; G: water distance / 240 m; B unused |
| `surface_detail.png` | 512² | RGBA: limestone grain, soil, sparse scrub, cultivation furrows |
| `cliff_detail.png` | 512² | Periodic greyscale rock strata, repeated in RGB |
| `decoration.json` | 96 centres | Seeded decorative scrub positions, aligned to actual collision at startup |

Surface/cliff textures are original periodic procedural artwork (CC0 1.0).
Masks retain the supplied terrain's DTM and coastline attribution/licensing;
see `../ATTRIBUTION.txt`. Agricultural parcels are plausible procedural visual
patterns, not surveyed historical land use. Coast distance only colours the
existing water; it does not define or change coastline/terrain geometry.

Texture import settings intentionally keep data channels lossless, disable
automatic 3D compression and alpha-border colour repair, and generate mipmaps.
The alpha channel is boundary DATA, not transparency. Shader samplers read
these masks without `source_color`; colour uniforms handle surface palettes.

Regenerate only decorative assets from the repository root:

```sh
python3 -m pip install numpy scipy Pillow
python3 tools/generate_malta_landscape.py
godot --headless --path . --editor --import --quit
```

The generator opens `terrain.glb` and `world_data.json` read-only, refuses
unexpected source-node transforms and writes only in this directory. It never
runs `assets/malta/source/build_terrain.py` or changes measured elevations.
